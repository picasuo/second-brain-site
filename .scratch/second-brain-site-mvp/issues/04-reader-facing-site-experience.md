# 04 — Reader-Facing Site Experience

**What to build:** Deliver the complete reader-facing Home, Notes Index and Published Note experience on top of the verified publication model. The site gives a clear personal introduction and supports calm, accessible long-form reading without presenting unsupported navigation features.

**Blocked by:** 03 — Safe Linked Published Note Rendering

**Status:** ready-for-agent

- [ ] Home presents the agreed provisional introduction and a clear “浏览笔记” entry to Notes Index, without embedding a note list or inventing author identity details.
- [ ] Notes Index presents all Published Note in Published Note Order with title, date and read-only Canonical Tag metadata.
- [ ] Published Note presents metadata, rendered Markdown and the Table of Contents; Canonical Tag is visible but neither filters nor links anywhere.
- [ ] Contextual Navigation is the only navigation: Home enters Notes Index and Published Note returns to Notes Index; no persistent global navigation is rendered.
- [ ] The visual language is bright, restrained and editorial with a small amount of engineering character; configuration and visual assets remain replaceable.
- [ ] Desktop and mobile reading layouts meet keyboard navigation, visible focus and readable contrast requirements in their supported light and dark appearances.
- [ ] There is no search UI, Tag Browsing, tag-specific route or Tag-filter URL.
